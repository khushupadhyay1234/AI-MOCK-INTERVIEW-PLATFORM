# AI Mock Interview Platform

## Features

- Resume Upload
- ATS Resume Analysis
- Skill Extraction
- Company Specific Interviews
- DSA Interview Questions
- AI Answer Evaluation
- Interview Analytics
- Learning Roadmap
- Weak Topic Analysis
- SQLite Interview History

## Tech Stack

- Python
- Streamlit
- Groq LLM
- SQLite
- PyPDF2

## Run Locally

pip install -r requirements.txt
streamlit run app.py
